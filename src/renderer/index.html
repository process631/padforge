Trigger range

Left handle: how far you must pull before the press counts. Raise it to ignore light touches. Right handle: where the trigger counts as fully pressed. Lower it for a "hair trigger" that fires sooner, without pulling all the way. The green bar shows your trigger live.

Benchmark

Measures for 10 seconds and keeps the result. Run it once before overclocking and click Set as baseline, then run it again afterward to see the improvement. The chart shows how often each gap between reports happened. A single tall bar on the left is ideal.

Overclock over USB

Checking…

A stock DualSense reports about 250 times a second over USB. Raising that takes a USB filter driver. PadForge works with hidusbf, the driver controller-overclock guides use. You download and install it yourself; PadForge never installs drivers.

Target rate
  1. Download hidusbf and unzip it to a permanent folder.
  2. Point PadForge at Setup.exe from that folder.
  3. Run the tool and approve the admin prompt. Tick Show all devices, select your DualSense (VID 054C), tick Filter on device, choose your target rate, then click Install service and Restart.
  4. Replug the controller, then run the benchmark above to confirm the new rate.

Windows Memory Integrity can block unsigned drivers; hidusbf's readme explains the options. Overclocking only affects USB, and you can undo it from the same tool.
